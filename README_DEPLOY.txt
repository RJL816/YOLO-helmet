【项目简介】
云视智盔是一款基于改进 YOLO11 的电动车头盔检测监控系统。
创新融合 Wise-IoU 动态损失函数与 DySample 可学习上采样技术，
配合 ByteTrack 目标跟踪、滑动窗口投票机制，实现高精度实时检测。
系统支持违章自动抓拍、难例自动挖掘、WebSocket 实时推送。

========================================================================
【部署方式一：Docker 部署（推荐）】
========================================================================

要求：
  - 已安装 Docker Desktop（Windows/Mac）或 Docker（Linux）
  - 首次构建需要 5-10 分钟

步骤：
  1. 双击运行 start_docker.bat
  2. 等待镜像构建完成
  3. 自动启动服务

访问：
  - 监控大屏：http://localhost:8000
  - API 文档：http://localhost:8000/docs

停止服务：
  - 命令行执行：docker-compose down

查看日志：
  - 命令行执行：docker-compose logs -f

========================================================================
【部署方式二：本地 Python 运行】
========================================================================

要求：
  - Python 3.8 或更高版本
  - 推荐使用虚拟环境

步骤：

1. 创建虚拟环境（可选但推荐）：
   conda create -n helmet python=3.10
   conda activate helmet

2. 安装依赖：
   pip install -r requirements_web.txt

3. 安装自定义 ultralytics（包含 Wise-IoU 和 DySample 改进）：
   pip install -e .

4. 启动服务：
   双击运行 start_web.bat
   或执行命令：
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

访问：
  - 监控大屏：http://localhost:8000
  - API 文档：http://localhost:8000/docs

========================================================================
【系统技术栈】
========================================================================

后端：
  - FastAPI >= 0.111.0
  - Uvicorn ASGI 服务器
  - SQLAlchemy ORM + SQLite
  - WebSocket 实时推送
  - MJPEG 视频流

AI 引擎：
  - YOLO11 + Wise-IoU 损失函数
  - DySample 动态上采样
  - ByteTrack 多目标跟踪

前端：
  - Vue 3 (CDN)
  - Element Plus UI 组件
  - ECharts 数据可视化

========================================================================
【项目核心创新】
========================================================================

1. Wise-IoU (WIoU) 损失函数
   - 动态关注机制，通过中心点距离提升检测精度

2. DySample 动态上采样
   - 可学习偏移量的动态采样，提升小目标识别率

3. 滑动窗口投票机制 (N=7)
   - 消除单帧误检，防止检测结果闪烁

4. 骑车人-头盔空间关联
   - 垂直投影法判断头盔是否在车辆上方

5. 违章抓拍 + 难例挖掘
   - 自动保存违规证据
   - 自动收集边缘样本用于模型优化
